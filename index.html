Este es un ejemplo para poder modificar el contenido de una tabla usando js
Paso 1. Creamos la definicion inicial de la tabla para ello usamos el tag de tabla <table> con las siguientes caracteristicas:

  • id="table01" -> le asigamos un id para poder acceder al elemento
  • width="100%" -> le asigamos un ancho de 100%
  • Agregamos los encabezados/headers con el tag <th>
